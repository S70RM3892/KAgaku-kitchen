# ケミカル・キッチン

注文の品を作って届けるクッキングゲーム。**化学4モード＋早押しクイズ**と**英語3モード**から選べる（タイトル画面と、マルチプレイのロビーで「🧪 化学／🔤 英語」を切り替え）。

| モード | やること | 覚えられること |
|---|---|---|
| **反応式モード** | 試薬棚から反応物を選び、**触媒**と**加熱の有無**を決めて反応式を組む | 製法・反応条件・触媒・濃/希・係数 |
| **組成モード** | 周期表の棚から元素を選んで、物質の**分子式**を組み立てる | 化学式・物質の性質 |
| **官能基モード** | 骨格と官能基の**部品で有機化合物を組む**／2つの化合物を**検出試薬で見分ける** | 官能基・代表的な有機化合物・検出反応 |
| **早押しクイズ**（化学） | ヒントが少しずつ出る中で、**物質を選択肢から早押し**（みんなで同じ問題） | 物質の性質・反応・分類を手がかりから思い出す |
| **語根モード**（英語） | **接頭辞・語根・接尾辞**を組んで英単語を作る／単語を部品に分ける | 語の成り立ち・初見の単語の推測・品詞の変化 |
| **構文モード**（英語） | 構文の語句を**正しい順に並べる**（①②は中身の入る場所） | 和文英訳の骨組み（too…to・It is not until…that・No sooner had…than など） |
| **見分けモード**（英語） | 紛らわしい2語から**例文の空所に入る方を選ぶ** | borrow/lend・affect/effect・economic/economical など |
| **無機イオンモード** | **陽イオンと陰イオンを電荷がつり合うように組む**／錯イオンを組む／**半反応式の e⁻・H⁺・H₂O の数を合わせる** | イオン式・酸・塩基・塩・沈殿・錯イオン・酸化剤と還元剤 |

どれも、ひとりで練習するほかに**友達と協力・対戦**（2〜4人、それぞれのスマホ/PC）で遊べる。習熟度とベストスコアはモードごとに別々に記録される（旧版の記録は組成モードに引き継がれる）。

## 基本の流れ（全モード共通）

- **客（伝票）ごとに専用の鍋**がある。伝票をタップしてその客を選び、棚から材料を入れて反応させる
- **注文どおりの物質ができたら自動で提供**（持って運ぶ操作はない）
- 反応中は次の客に自動で切り替わるので、何人分も並行して作れる
- 違う物ができたら −5。反応しなかった・違う物ができた鍋は、放置すると燃える（同じ伝票をもう一度タップで消火）

## 反応式モードの流れ

1. 伝票の物質（名前か性質）を見て、作る反応を思い出す
2. 試薬棚をタップして選んだ客の鍋へ（同じ試薬をもう一度で係数+1。**濃／希**は別の試薬）
3. 必要なら棚の最下段の**触媒・脱水剤**をセット、🔥ボタンで **常温 → 加熱 → 高温・高圧** を切り替え
4. 「反応」→ 注文どおりなら自動で提供。途中の**中間体**（SO₂・NO₂・NaHCO₃など）ができたら鍋に残るので、そのまま次の反応へ＝多段階合成

条件が合わないと反応しない。序盤のステージは理由が出る（「加熱が必要」「濃度が違う（濃塩酸を使う）」「MnO₂は触媒として使う」など）。
いらない加熱・触媒でも反応はするが、報酬×0.7で習熟★は上がらない。

### 収録している反応（61本、すべて原子数の保存をテストで確認）
- **気体の製法**：H₂・O₂（H₂O₂／KClO₃＋MnO₂触媒）・Cl₂（MnO₂は酸化剤／さらし粉）・HCl・NH₃・CO₂・H₂S・SO₂・NO/NO₂（希/濃硝酸）・CO（濃硫酸の脱水作用）・CH₄・HF・C₂H₂・N₂ など
- **沈殿**：AgCl・AgBr・AgI・Ag₂O・Ag₂CrO₄・PbCrO₄・PbCl₂・PbI₂・BaSO₄・CaCO₃・Cu(OH)₂・Fe(OH)₃・CuS/PbS（H₂Sを先に作って注ぐ）
- **工業的製法**（製法名つきで注文）：ハーバー・ボッシュ法（Fe₃O₄・高温高圧）、接触法（V₂O₅）、オストワルト法（Pt）、アンモニアソーダ法、石灰石の熱分解 など
- **有機**：エステル化、エタノールの分子間/分子内脱水（分子数で生成物が変わる）、ニトロ化（混酸）、スルホン化（濃硫酸が反応物）、塩素化（Fe）、アセチレンの三分子重合、水素付加（Ni/Pt）、アルコール発酵（酵母）、コルベ・シュミット反応（高温高圧）、アセチル化 など

## 画面の向き（横持ち・縦持ち）

ゲーム中の画面は**持ち方に合わせて自動で切り替わる**（⚙設定の「画面の向き」で横持ち／縦持ちに固定もできる）。途中で持ち替えても、鍋の中身や選んでいる客はそのまま。

### 横持ち
- **左端・右端に棚**：組成モードは周期表を **1〜9族（左）と 10〜18族（右）** に分けて置く。反応式モードは試薬棚を4列ずつ左右に
- **中央に客（伝票）の列**：客ごとの鍋の中身・反応中・失敗の状態が**いつでも全員に見える**。伝票の上で反応・加熱・捨てる操作もできる
- 棚の上に「入れ先 → 2 窒素」のように、いまタップすると入る客が出る

### 縦持ち
- **上に客（伝票）の列、下に棚**。棚は親指が届く下半分に置く
- 組成モード（スマホ）は周期表を **1〜9族（上段）と 10〜18族（下段）** の2段にして、1マスを大きくする（幅360〜390pxのスマホで1マスの幅が約34〜37px。1枚の周期表を縦画面に詰めたときの約2倍）。第7周期は注文に出ないので細い行にしてある
- 加熱・反応・捨てるは、選んでいる客に対する**大きな操作ボタン**にまとめた。組成モードは周期表の空き（3〜9族×第2・3周期）に、反応式モードは棚のすぐ上に出る
- 客の数と画面の高さに合わせて、伝票の並び（1段・2×2・3×2）と棚の行の高さを自動で決める。タブレットの縦持ちは周期表を左右つなげた1枚（本物の並び）で表示する

### 共通
- 協力では、同じ客の鍋に仲間が入れた分が名前の頭文字タグつきで並び、仲間が選んでいる客には色の点が出る。上のバーには各自の「→ 客番号」が出る
- 「横持ち」「縦持ち」に固定していて逆向きに持つと、持ち替えの案内が出る（「持ち方に合わせる」で自動に戻せる）
- Android の Chrome などでは「⛶ 全画面」ボタンで全画面にして、いまの向きに固定できる。iPhone はホーム画面に追加するとアドレスバーなしで遊べる

## 組成モードの流れ

1. 伝票の物質（名前か性質）を見て、**本物の周期表（1〜18族×第1〜7周期、全88マス＋ランタノイド・アクチノイド欄）**から元素をタップして選んだ客の鍋へ（長押しで連続投入）。タップした元素の名前・周期・族・分類が表の上に出る
2. 「加熱」で反応。注文どおりの分子式なら自動で提供。レシピに無い組成は失敗、別の物質ができたら −5
3. ヒントは元素→化学式の順

ステージは ガス屋の朝（気体）／沈殿亭／性質オーダー／有機の夜／京大ラッシュ の5つ＋苦手克服ラン。協力では族ごとに担当が分かれ（2人なら奇数族と偶数族）、HとOは必ず別担当になる。停電中は元素記号が消えるので、位置で探す。

## 官能基モードの流れ

棚は**左に骨格**（H–・CH₃–・C₂H₅–・C₃H₇–・C₆H₅–・o/m/p-C₆H₄・CH₂=CH–・–CH=CH–（シス／トランス）・HC≡C–）、**右に官能基**（–OH・–CHO・–CO–・–COOH・–COO–・–O–・–NH₂・–NO₂・–SO₃H・–NHCO–・–CH(OH)–・–Cl）、**最下段に検出試薬8種**（銀鏡・フェーリング・I₂+NaOH・FeCl₃・NaHCO₃・Na・さらし粉・臭素水）。

- **組み立ての注文**（名前か性質で出る）：部品を鍋に入れて化合物を組む。例：アセトン＝CH₃–×2＋–CO–、サリチル酸＝o-C₆H₄＋–OH＋–COOH。そろえば自動で提供
  - 別の化合物になったら −5（「それはエタノール」のように何ができたかが出る）。存在しない組み合わせは失敗で、段階が低いほど理由が詳しい（「置換基の位置（o-・m-・p-）が違う」「部品が足りない」など）
- **見分けの注文**（例：アセトアルデヒドとアセトン）：区別できる検出試薬を**1つ選んだ瞬間に判定**。正解なら両方の結果（「銀が析出／変化なし」）が出る。結果が同じになる試薬は −5 で、総当たりはできない
- ヒントは 分類→示性式（性質の注文は 名前→示性式、見分けは 着目点→試薬）
- 図鑑では化合物ごとに、部品・分子式・性質と、**検出試薬8種の結果の表**が見られる

### 段階（最初から全部選べる）
| | ステージ | 内容 |
|---|---|---|
| 基礎 | 官能基入門 | アルコール・アルデヒド・ケトン・カルボン酸・エステル・エーテル・エチレン・アセチレン。名前で注文 |
| 基礎＋ | 検出反応ラボ | 級数の違うアルコール・異性体の入口。銀鏡・ヨードホルム・NaHCO₃・Na で見分ける注文が入る |
| 標準 | 芳香族の店 | フェノール類・サリチル酸の仲間・アニリン・ニトロベンゼン など。FeCl₃・さらし粉・臭素水 |
| 応用 | 異性体の迷宮 | o-/m-/p-（キシレン・フタル酸類）、シス-トランス（マレイン酸・フマル酸）、C₃H₆O₂の異性体、ヨードホルムのひっかけ |
| 京大 | 京大ラッシュ（有機） | 全範囲・性質のみの注文。失敗の理由は出ない。停電・延焼あり |

化合物48種・見分け27組。部品の原子数の合計が示性式と一致することと、見分けの正解が「両方の結果が確定していて陽性・陰性が分かれる試薬」だけであることをテストで確認している。教科書や文献で扱いが割れる反応（ギ酸とフェーリング液、エステルのヨードホルム反応の一部など）は正解に使わず、図鑑では「？」と表示する。

協力では2人なら**骨格担当と官能基担当**に分かれる（検出試薬は半分ずつ）ので、ほぼ全部の化合物が2人の部品を合わせないと組めない。

## 無機イオンモードの流れ

棚は**左に陽イオン20種**（H⁺・Na⁺・NH₄⁺・Ag⁺・Cu⁺・Ca²⁺・Ba²⁺・Zn²⁺・Cu²⁺・Fe²⁺・Fe³⁺・Al³⁺・Pb²⁺・Sn²⁺・Mn²⁺・Cr³⁺ など）、**右に陰イオン24種**（OH⁻・O²⁻・ハロゲン化物イオン・NO₃⁻・SO₄²⁻・HSO₄⁻・SO₃²⁻・S²⁻・S₂O₃²⁻・CO₃²⁻・HCO₃⁻・PO₄³⁻・HPO₄²⁻・H₂PO₄⁻・CH₃COO⁻・C₂O₄²⁻・ClO₃⁻、最下段は酸化剤のイオン MnO₄⁻・Cr₂O₇²⁻・CrO₄²⁻・ClO⁻）、**左の最下段に配位子と半反応式の部品**（NH₃・CN⁻・H₂O・e⁻）。

- **物質の注文**（名前か性質で出る）：電荷がつり合うようにイオンを入れる。例：Al₂(SO₄)₃＝Al³⁺×2＋SO₄²⁻×3、硫酸＝H⁺×2＋SO₄²⁻
  - 酸性塩・多価の酸は、H⁺を分けて入れてもよい（NaHSO₄＝Na⁺＋HSO₄⁻ でも Na⁺＋H⁺＋SO₄²⁻ でも正解）
  - 別の物質になったら −5（「それは水酸化亜鉛」など）。電荷がつり合わない／比が違う／配位数が違うものは失敗で、段階が低いほど理由が詳しい（「電荷がつり合わない（＋3／−2）」「配位数が違う（ジアンミン銀(I)イオンの配位数は2）」）
- **錯イオン・錯塩**：中心の金属イオン＋配位子を配位数ぶん。例：[Cu(NH₃)₄]²⁺＝Cu²⁺＋NH₃×4、K₄[Fe(CN)₆]＝K⁺×4＋Fe²⁺＋CN⁻×6
- **半反応式の注文**（例：MnO₄⁻ → Mn²⁺、硫酸酸性）：**e⁻・H⁺・H₂O（・OH⁻）の数**を入れる。電子の数が違えば酸化数の変化（Mn：+7 → +2）が、H⁺・H₂O の数が違えば合わせ方が出る
- 図鑑では物質ごとにイオンの内訳・分類・配位数・性質、半反応式ごとに完成した式・酸化数の変化が見られる

### 段階（最初から全部選べる）
| | ステージ | 内容 |
|---|---|---|
| 基礎 | イオンの組み立て | 塩化物・硫酸塩・硝酸塩・酸化物・強酸・強塩基 |
| 基礎＋ | 酸・塩基・塩 | 弱酸・多価の酸・酸性塩・リン酸塩・緩衝液の成分（中和滴定・加水分解・二段階中和でよく出るもの） |
| 標準 | 酸化還元 | 酸化剤・還元剤の物質（KMnO₄・K₂Cr₂O₇・Na₂S₂O₃・KI・シュウ酸 など）と、半反応式18本 |
| 応用 | 沈殿と錯イオン | 沈殿の色と溶け方（系統分析・モール法）、錯イオン・錯塩 |
| 京大 | 京大ラッシュ（無機・理論） | 全範囲・性質のみの注文と、中性・塩基性の MnO₄⁻ を含む半反応式20本。失敗の理由は出ない |

物質95種・半反応式20本。各物質について「イオンの原子数の合計が化学式と一致する」「電荷の合計が0（錯イオンはその電荷）になる」こと、各半反応式について「両辺で原子と電荷がつり合い、e⁻・H⁺・H₂O・OH⁻ の数が式と一致する」ことをテストで確かめている。

協力では2人なら**陽イオン担当と陰イオン担当**に分かれる（配位子・e⁻・H₂O は半分ずつ）ので、ほぼ全部の物質が2人のイオンを合わせないと組めない。

## 早押しクイズ

組成・官能基・無機イオンモードの物質から作った165問。ヒントは数秒ごとに1つずつ増え、「分類 → 検出反応・性質 → 化学式」の順にだんだん答えに近づく。

- 分かった瞬間に選択肢（4つ、応用・京大は6つ）をタップ。**いちばん早く正解した人**が得点し、ヒントが少ないうちほど高い（10＋6×残りのヒント数）
- 間違えると**その問題にはもう答えられず**、早いほど大きく減点（3＋2×残りのヒント数）。4択の当てずっぽうは期待値がマイナスになるようにしてある
- 全員が間違えるか、最後のヒントのあと6秒で正解発表、次の問題へ。10問（京大は15問）で終わり
- ソロは自己ベスト、対戦は個人戦、協力はチームの合計点。答えられなかった問題は次からよく出る
- 段階：気体と沈殿 → 無機の物質 → 有機化合物 → 沈殿と錯イオン（6択）→ 京大ラッシュ（全範囲・ヒントが速い・6択）

## 英語の3モード

化学のモードと同じ仕組み（客ごとの鍋・自動で提供・協力／対戦・忙しさ・縦持ち・図鑑・苦手の再出題）で、部品が英語になる。どれも基礎→基礎＋→標準→応用→京大の5段階で、最初から全部選べる。

- **語根モード**：棚は左に接頭辞20（in-・re-・pre-・trans-・ex- など）、右に語根20（spect＝見る・port＝運ぶ・dict＝言う・ject＝投げる・duce/duct＝導く・mit/miss＝送る など）、最下段に接尾辞8（-ion・-ive・-able・-ible・-ure・-or・-ent・-ary）。「予測する」→ pre- ＋ dict（意味の注文）、「transport」→ trans- ＋ port（分解の注文）。単語112語。部品をつなげるとつづりになる語だけを収録し、テストで確かめている
- **構文モード**：語句40と①②を、型どおりの**順番で**入れる。「①すぎて②できない」→ too ① to ②。京大ラッシュは日本語の例文だけで出る。語順違い・足りない語句は失敗、別の構文になったら−5。構文24（so…that・such…that・too…to・enough to・not only…but also・形式主語・強調構文・whether・the 比較級・助動詞＋have・I wish・If it were not for・so that・worth・cannot help・not until・No sooner・Hardly など）
- **見分けモード**：紛らわしい24組48語。例文の空所に入る語を選んだ瞬間に判定し、間違えると選んだ語の意味が出る。応用・京大は日本語のヒントなし

協力では2人なら左の棚と右の棚で担当が分かれる（語根モードは接頭辞担当と語根担当、見分けモードはペアの2語がふつう別々の担当）。

## 遊び方（マルチプレイ）

1. トップで名前を入れて「部屋を作る」→ 4文字の部屋コードとQRが出る
2. 友達はQRを読む／招待リンクを開く／「部屋に入る」でコード入力
3. ホストがゲーム（反応式／組成／官能基／無機イオン）、協力／対戦、ステージ、忙しさを選んで「開店する」

### 協力モード
- **棚の分担**：試薬棚と触媒の列ごとに担当が決まる。2人なら約8割の反応が2人の担当にまたがるように並べてある
- **客ごとに1つの鍋を全員で使う**。伝票をタップして自分が作る客を選び、入れた材料は「誰が入れたか」ごとに分けて表示される（自分の分は大きく、仲間の分は名前の頭文字タグつき）
- **精錬は全員分を合わせて判定**。たとえば自分が Fe・O₃、仲間が H₃ を入れれば Fe(OH)₃ がそろい、自動精製ONならその瞬間に反応して提供される
- 上のバーには各自が選んでいる客の番号、伝票には選んでいる仲間の色の点が出る
- 担当外の試薬・触媒をタップすると担当者に**リクエスト**。相手の画面で光り、相手がタップすると**頼んだ人の鍋**（頼んだ人が選んでいる客）に入る（触媒もセットされる）
- 注文・得点は全員で共有。40秒ごとに**棚替え**
- 2人以上で入れた鍋が提供されると**連携ボーナス×1.2**。💬でスタンプ

### 対戦モード
- 注文ボードは全員共通。**先に正しく届けた人だけ**が得点（相手の完成品は上のバーで見える）
- 届けると首位の相手に**おじゃま**：手順の多い反応（多段階・触媒・高温高圧）・VIP・4連続以上・ラッシュ中ほど強い
  - 1=煙幕（棚のラベルが消える） 2=在庫切れ 3=引火 4以上=大惨事
- おじゃまは3.5秒後に着弾。それまでに自分も届ければ**相殺**、余りは打ち返せる
- 鍋は**客ごと×プレイヤーごと**。相手が作っている客には伝票に相手の色の点が出る。違う物を作ると −5

習熟度（★）と苦手の記録は各自の端末に保存される。マルチプレイでも注文は参加者全員の苦手に寄せて出る。

## 通信のしくみ

- [PeerJS](https://peerjs.com/) 1.5.5（WebRTC）を `vendor/` に同梱。ホストの端末がゲームの正（権威）で、参加者は操作を送り、ホストが状態を配る
- 接続の仲介（シグナリング）は PeerJS の無料クラウドサーバー、つながりにくい回線では PeerJS 既定の TURN サーバー経由になる。サーバーを自前で用意する必要はない
- 参加者の操作は手元で先に反映し（予測）、ホストの確定状態で上書きするので、タップの反応は遅れない
- ホストがアプリを裏に回すと全員一時停止になる。ホストが切断すると部屋は終了する

つながらないときは、同じWi-Fiにそろえる／片方をモバイル回線に切り替えるのが効く（学校や会社のネットワークはWebRTCを止めていることがある）。

## 開発・テスト

```sh
npm test                      # 反応データ・官能基／無機イオンモードのデータ（原子数・電荷・判定）とゲームエンジンのテスト（Node 18+）
```
