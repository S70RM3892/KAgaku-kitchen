# ケミカル・キッチン

注文の物質を作って届ける化学クッキングゲーム。遊び方は2つのモードから選べる（タイトル画面と、マルチプレイのロビーで切り替え）。

| モード | やること | 覚えられること |
|---|---|---|
| **反応式モード** | 試薬棚から反応物を選び、**触媒**と**加熱の有無**を決めて反応式を組む | 製法・反応条件・触媒・濃/希・係数 |
| **組成モード** | 周期表の棚から元素を選んで、物質の**分子式**を組み立てる | 化学式・物質の性質 |

どちらも、ひとりで練習するほかに**友達と協力・対戦**（2〜4人、それぞれのスマホ/PC）で遊べる。習熟度とベストスコアはモードごとに別々に記録される（旧版の記録は組成モードに引き継がれる）。

## 忙しさ（タイトル画面・ロビーで選択）

| 忙しさ | 注文の出かた | 得点 |
|---|---|---|
| ☕ ひま | ゆっくり、並ぶ伝票が1枚少ない、制限時間長め | ×0.8 |
| 🔥 ふつう | 標準 | ×1 |
| 🔥🔥 いそがしい | 速く、1枚多く並ぶ | ×1.15 |
| 🔥🔥🔥 てんてこまい | かなり速く、2枚多く並ぶ | ×1.3 |
| ∞ 無限オーダー | **伝票が空いた瞬間に次の注文が来て常に満席**。時間切れは−5でコンボは切れない | ×1.5 |

自己ベストは忙しさごとに別々に記録される。★の基準点も忙しさに合わせて変わる。

## 基本の流れ（両モード共通）

- **客（伝票）ごとに専用の鍋**がある。伝票をタップしてその客を選び、棚から材料を入れて反応させる
- **注文どおりの物質ができたら自動で提供**（持って運ぶ操作はない）
- 反応中は次の客に自動で切り替わるので、何人分も並行して作れる
- 違う物ができたら −5。反応しなかった・違う物ができた鍋は、放置すると燃える（同じ伝票をもう一度タップで消火）

## 反応式モードの流れ

1. 伝票の物質（名前か性質）を見て、作る反応を思い出す
2. 試薬棚をタップして選んだ客の鍋へ（同じ試薬をもう一度で係数+1。**濃／希**は別の試薬）
3. 必要なら棚の最下段の**触媒・脱水剤**をセット、🔥ボタンで **常温 → 加熱 → 高温・高圧** を切り替え
4. 「反応」→ 注文どおりなら自動で提供。途中の**中間体**（SO₂・NO₂・NaHCO₃など）ができたら鍋に残るので、そのまま次の反応へ＝多段階合成

条件が合わないと反応しない。序盤のステージは理由が出る（「加熱が必要」「濃度が違う（濃塩酸を使う）」「MnO₂は触媒として使う」など）。
いらない加熱・触媒でも反応はするが、報酬×0.7で習熟★は上がらない。

### 収録している反応（61本、すべて原子数の保存をテストで確認）
- **気体の製法**：H₂・O₂（H₂O₂／KClO₃＋MnO₂触媒）・Cl₂（MnO₂は酸化剤／さらし粉）・HCl・NH₃・CO₂・H₂S・SO₂・NO/NO₂（希/濃硝酸）・CO（濃硫酸の脱水作用）・CH₄・HF・C₂H₂・N₂ など
- **沈殿**：AgCl・AgBr・AgI・Ag₂O・Ag₂CrO₄・PbCrO₄・PbCl₂・PbI₂・BaSO₄・CaCO₃・Cu(OH)₂・Fe(OH)₃・CuS/PbS（H₂Sを先に作って注ぐ）
- **工業的製法**（製法名つきで注文）：ハーバー・ボッシュ法（Fe₃O₄・高温高圧）、接触法（V₂O₅）、オストワルト法（Pt）、アンモニアソーダ法、石灰石の熱分解 など
- **有機**：エステル化、エタノールの分子間/分子内脱水（分子数で生成物が変わる）、ニトロ化（混酸）、スルホン化（濃硫酸が反応物）、塩素化（Fe）、アセチレンの三分子重合、水素付加（Ni/Pt）、アルコール発酵（酵母）、コルベ・シュミット反応（高温高圧）、アセチル化 など

### ステージ
| | 内容 | 難しさの仕掛け |
|---|---|---|
| 1 ガス屋の朝 | 気体の実験室製法 | 失敗の理由が詳しく出る |
| 2 沈殿亭 | 沈殿反応＋気体 | 加熱がいらない反応の見極め、VIP客 |
| 3 工業ライン | 工業的製法 | 触媒・高温高圧・最大3段階の合成、在庫切れ（別ルートで回避） |
| 4 有機の夜 | 有機反応 | 触媒・温度・分子数で生成物が変わる、停電（棚のラベルが消える） |
| 5 京大ラッシュ | 全範囲 | 性質のみの注文、**係数も判定**、失敗の理由は出ない |

トップの「係数判定」をONにすると、どのステージでも係数まで合わせないと反応しない。

## 画面の向き（横持ち・縦持ち）

ゲーム中の画面は**持ち方に合わせて自動で切り替わる**（⚙設定の「画面の向き」で横持ち／縦持ちに固定もできる）。途中で持ち替えても、鍋の中身や選んでいる客はそのまま。

### 横持ち
- **左端・右端に棚**：組成モードは周期表を **1〜9族（左）と 10〜18族（右）** に分けて置く。反応式モードは試薬棚を4列ずつ左右に
- **中央に客（伝票）の列**：客ごとの鍋の中身・反応中・失敗の状態が**いつでも全員に見える**。伝票の上で反応・加熱・捨てる操作もできる
- 棚の上に「入れ先 → 2 窒素」のように、いまタップすると入る客が出る

### 縦持ち
- **上に客（伝票）の列、下に棚**。棚は親指が届く下半分に置く
- 組成モード（スマホ）は周期表を **1〜9族（上段）と 10〜18族（下段）** の2段にして、1マスを大きくする（幅360〜390pxのスマホで1マスの幅が約34〜37px。1枚の周期表を縦画面に詰めたときの約2倍）。第7周期は注文に出ないので細い行にしてある
- 加熱・反応・捨てるは、選んでいる客に対する**大きな操作ボタン**にまとめた。組成モードは周期表の空き（3〜9族×第2・3周期）に、反応式モードは棚のすぐ上に出る
- 客の数と画面の高さに合わせて、伝票の並び（1段・2×2・3×2）と棚の行の高さを自動で決める。タブレットの縦持ちは周期表を左右つなげた1枚（本物の並び）で表示する

### 共通
- 協力では、同じ客の鍋に仲間が入れた分が名前の頭文字タグつきで並び、仲間が選んでいる客には色の点が出る。上のバーには各自の「→ 客番号」が出る
- 「横持ち」「縦持ち」に固定していて逆向きに持つと、持ち替えの案内が出る（「持ち方に合わせる」で自動に戻せる）
- Android の Chrome などでは「⛶ 全画面」ボタンで全画面にして、いまの向きに固定できる。iPhone はホーム画面に追加するとアドレスバーなしで遊べる

## 設定（タイトルまたは一時停止中の「⚙ 設定」）

| 設定 | 内容 |
|---|---|
| 自動精製 | 客の鍋に必要なもの（と条件）がそろった瞬間（協力は全員が入れた分を合わせて判定）に自動で反応して提出（初期設定ON。マルチプレイはロビーでホストが決める） |
| 画面の向き | 自動（持ち方に合わせる）／横持ち／縦持ち |
| 横持ちの棚の配置 | 左右に分割／下にまとめる（タブレット向け） |
| 反応後は次の客へ | 反応を押したら空いている客を自動で選ぶ |
| 元素名・試薬名 | 棚のマスに名前も出す（覚え始め向け） |
| 分類の色分け | OFFで全部同じ色（位置だけで覚える上級者向け） |
| 鍋・伝票の文字 | 小・中・大 |
| 長押しで連続投入／BGM／振動 | ON・OFF |

## 組成モードの流れ

1. 伝票の物質（名前か性質）を見て、**本物の周期表（1〜18族×第1〜7周期、全88マス＋ランタノイド・アクチノイド欄）**から元素をタップして選んだ客の鍋へ（長押しで連続投入）。タップした元素の名前・周期・族・分類が表の上に出る
2. 「加熱」で反応。注文どおりの分子式なら自動で提供。レシピに無い組成は失敗、別の物質ができたら −5
3. ヒントは元素→化学式の順

ステージは ガス屋の朝（気体）／沈殿亭／性質オーダー／有機の夜／京大ラッシュ の5つ＋苦手克服ラン。協力では族ごとに担当が分かれ（2人なら奇数族と偶数族）、HとOは必ず別担当になる。停電中は元素記号が消えるので、位置で探す。

## 遊び方（マルチプレイ）

1. トップで名前を入れて「部屋を作る」→ 4文字の部屋コードとQRが出る
2. 友達はQRを読む／招待リンクを開く／「部屋に入る」でコード入力
3. ホストがゲーム（反応式／組成）、協力／対戦、ステージ、忙しさを選んで「開店する」

### 協力モード
- **棚の分担**：試薬棚と触媒の列ごとに担当が決まる。2人なら約8割の反応が2人の担当にまたがるように並べてある
- **客ごとに1つの鍋を全員で使う**。伝票をタップして自分が作る客を選び、入れた材料は「誰が入れたか」ごとに分けて表示される（自分の分は大きく、仲間の分は名前の頭文字タグつき）
- **精錬は全員分を合わせて判定**。たとえば自分が Fe・O₃、仲間が H₃ を入れれば Fe(OH)₃ がそろい、自動精製ONならその瞬間に反応して提供される
- 上のバーには各自が選んでいる客の番号、伝票には選んでいる仲間の色の点が出る
- 担当外の試薬・触媒をタップすると担当者に**リクエスト**。相手の画面で光り、相手がタップすると**頼んだ人の鍋**（頼んだ人が選んでいる客）に入る（触媒もセットされる）
- 注文・得点は全員で共有。40秒ごとに**棚替え**
- 2人以上で入れた鍋が提供されると**連携ボーナス×1.2**。💬でスタンプ

### 対戦モード
- 注文ボードは全員共通。**先に正しく届けた人だけ**が得点（相手の完成品は上のバーで見える）
- 届けると首位の相手に**おじゃま**：手順の多い反応（多段階・触媒・高温高圧）・VIP・4連続以上・ラッシュ中ほど強い
  - 1=煙幕（棚のラベルが消える） 2=在庫切れ 3=引火 4以上=大惨事
- おじゃまは3.5秒後に着弾。それまでに自分も届ければ**相殺**、余りは打ち返せる
- 鍋は**客ごと×プレイヤーごと**。相手が作っている客には伝票に相手の色の点が出る。違う物を作ると −5

習熟度（★）と苦手の記録は各自の端末に保存される。マルチプレイでも注文は参加者全員の苦手に寄せて出る。

## GitHub Pages で公開する

ビルド不要の静的サイト。

1. このブランチを `main` にマージ
2. リポジトリの **Settings → Pages → Build and deployment** で Source を **Deploy from a branch**、Branch を `main` / `/(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

`.nojekyll` を置いてあるので Jekyll の処理は走らない。

## 通信のしくみ

- [PeerJS](https://peerjs.com/) 1.5.5（WebRTC）を `vendor/` に同梱。ホストの端末がゲームの正（権威）で、参加者は操作を送り、ホストが状態を配る
- 接続の仲介（シグナリング）は PeerJS の無料クラウドサーバー、つながりにくい回線では PeerJS 既定の TURN サーバー経由になる。サーバーを自前で用意する必要はない
- 参加者の操作は手元で先に反映し（予測）、ホストの確定状態で上書きするので、タップの反応は遅れない
- ホストがアプリを裏に回すと全員一時停止になる。ホストが切断すると部屋は終了する

つながらないときは、同じWi-Fiにそろえる／片方をモバイル回線に切り替えるのが効く（学校や会社のネットワークはWebRTCを止めていることがある）。

## 開発・テスト

```sh
npm test                      # 反応データ（原子数の保存・判定）とゲームエンジンのテスト（Node 18+）
python3 -m http.server 8000   # ローカルで開く → http://localhost:8000/
```

- `?net=local` を付けると、同じブラウザのタブ同士を BroadcastChannel でつなぐ（通信サーバー不要のテスト用）
- `?peerhost=127.0.0.1&peerport=9000&peerpath=/myapp` で自前の PeerServer（npm `peer`）に向けられる
